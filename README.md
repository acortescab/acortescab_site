# Alejandro Cortes Cabrejas | Portfolio

A modern personal portfolio website built with Next.js for Alejandro Cortes Cabrejas, a Tech Lead and Software Engineer based in Barcelona. The design blends a premium enterprise aesthetic with a sharper, more contemporary edge.

## Overview

This project showcases:
- a strong personal brand and headline
- a concise professional bio
- a clean career journey timeline
- a portfolio section for future case studies
- direct links to LinkedIn and email contact options
- access to the profile PDF included in the project

## Local development

From the app folder:

```bash
cd site
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Notes

- The PDF profile is copied into the public folder for browser access.
- The app uses Next.js + Tailwind CSS.
- This site is designed as a strong personal landing page and can be extended with real portfolio case studies later.
